# 缺失值与基金持仓时效修复

本轮落实上一轮维护建议中的前两项，只修改正常版本，不涉及 SkillHub 专用分支。2026-10-18 完成发布前复查。

## 缺失值契约

- `extract_features` 出口新增字段证据契约：无法取得的观测为 `None`，并在 `missing_features` 中列出；失败维度中的旧载荷不再进入评分。
- 真实 `0`、`False`、负利润和零 ROE 不属于缺失。均值、最低值保留真实零值，拒绝 NaN 和无穷值。
- 派生指标传播必要输入的缺失。风险数据缺失不代表安全，未知 RSI 不代表超卖，缺少 ROE 不代表困境反转；没有实现可靠计算的治理、VCP 等占位字段不参与判断。
- 评委规则读取缺失字段时弃权，不把 `get(..., 0/False)` 或布尔否定当成证据。未读取任何证据的恒真占位规则不再加分。复合规则在遇到未知输入时保守弃权。
- 风格识别复用正式特征提取，不再维护另一套默认零值。机构模型边界仍通过 `sanitize_features` 显式使用其既有默认值，因此模型估算仍不等于已核验事实。
- 现金流代理和 Serenity 卡位分仍是启发式估计，分别保留 `fcf_is_proxy`、`ai_score_is_heuristic` 标记；本轮不将其升级为真实模型或投资效果证明。

## 持仓报告期

- `fund_portfolio_hold_em` 的 `date` 是查询年份，不是报告季度。先查询当年，无法取得可识别记录时尝试上一年，再根据返回的 `季度` 字段选择最新的已结束报告期。
- 同一报告期内按占净值比例排序后取前十，不依赖接口行顺序。不能将多个季度的行拼成一组，也不能用不同季度的基金凑够三票。
- 发现缓存按查询年份、观察日期区分，TTL 为 1 小时；报告期快照另行带上报告期和观察日期。异常和空结果不缓存为一天有效数据。
- 超过 180 天的报告期标记 `stale`，这是产品的研究时效阈值，不是法定披露期限。缺少十条持仓、重复股票、异常权重、无法识别报告期均不用于量化因子风格判断。
- 基金代码限制为六位数字，避免缓存路径穿越；相同基金代码去重。原有 lite/medium/deep 扫描预算保留。
- 基金候选列表的备用路径也移除了固定的 2024 年日期，逐个探测最近四个已结束季度，只有实际取得且包含基金身份的记录才使用。

## 输出边界

`quant_signal` 随综合结果保存，HTML 基金区显示报告期、可用样本数和证据状态：

| 字段 | 含义 |
| --- | --- |
| `evidence_status` | available / partial / unavailable / not_scanned / not_applicable |
| `report_periods` | 本次取得的样本报告期，可能包含被降级的旧报告期 |
| `verified_funds_total` | 通过本地完整性和时效检查的基金数，不代表第三方审计 |
| `unavailable_reasons` | 过期、不完整、权重异常或无法取得等原因及数量 |
| `counts_by_period` | 按同一报告期统计疑似量化基金的目标股持仓数 |
| `is_quant_factor_style` | 同期至少三家有效样本时为 true；缺失样本导致无法排除时为 null；完整扫描样本未达标时为 false |

“第一大持仓低于 2%”只是一种分散持仓启发式，不证明基金采用量化策略。所有结果仅针对已扫描样本，不代表全市场基金全集；不同份额类别若代码不同，也仍需后续合并识别。

接口提供报告期但不提供可核验的公告时间，因此 `publication_date_verified=false`。当前获取到的旧报告不得当作历史时点已知数据，不用于无前视偏差回测。

接口依据：[AKShare 基金文档](https://github.com/akfamily/akshare/blob/main/docs/data/fund/fund_public.md)。

## 验证

- Python 3.13 全量离线测试：948 passed，1 skipped；新增 56 项回归。`git diff --check` 通过。
- 发布前补修：行业占位符不再误判为非 AI 链，负营收不生成复数 CAGR，基金代码去空格后去重，百分号持仓权重正确保留，六位代码也须检查市场后缀。
- 新增离线回归覆盖缺失/零值/负值、恒真规则、空数据全体弃权、失败维度、跨年、季度混排、过期、异常权重、缓存刷新、路径校验、去重及报告转义。
- 既有林奇测试修正为严格位于 20%-50% 区间的 25% 增长样本；同时断言无证据的“行业好懂”占位规则不计票。
- 未运行真实股票报告，未独立验证在线数据源、实际行情、收益率或胜率。GitHub CI 和发布状态以实际提交后的结果为准。

## 后续改进

后续仍建议推进角色推断与事实分层、数据源可观测性、发行人 ID 核验、宏观日历 provider；另外需要为公开持仓行为增加出处和时点，并合并同一基金不同份额的身份。这些不属于本轮已实现功能。
