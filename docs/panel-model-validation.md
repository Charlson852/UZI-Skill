# 评委模型验证与弃权合并

江恩、西蒙斯、索普、大卫·肖、阿斯尼斯目前只有阈值评分规则，尚无对应的模型验证生产流程。
`lib/panel_evidence.py` 明确登记各自缺口，评分器自动返回 `missing_model`；市场和流派排除优先。
行情完整或 `verified=true` 标记不能解除此门禁。解除前须实现对应模型、样本外验证和可追溯产物。
本次修复不建立统计套利、凯利或因子回测模型。

分析师覆盖合并会接收 `abstention_category`、`skip_reason`、`required_evidence` 和 `confidence`。
弃权统一保存 `score=null`，清除旧规则命中与权重，报告显示破折号。
恢复有效投票必须提供有限且在0至100之间的分数，并清除旧弃权元数据。
合并后重算有效票、弃权分类、流派分、共识及做空统计。
旧缓存进入综合研判时也执行模型门禁，覆盖文件不能直接让未实现模型恢复投票。
