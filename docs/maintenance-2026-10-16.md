## 下一批改进建议

1. **字段级缺失传播（高优先级）**：`stock_features` 部分历史字段仍把缺失默认成 0/False，可能被阈值规则当成事实。应建立逐字段缺失状态和来源映射，避免零值、缺失和不适用混淆。此次只修复分位与龙虎榜相关链路，未重写全部特征。
2. **基金持仓时效（高优先级）**：`quant_signal.HOLDINGS_QUARTER` 仍固定为 2025。后续应选择最新已披露报告期、缓存键带报告期、展示实际样本期，并对过期结果降级；不能简单用当前年份假定已披露。
3. **角色观点与交易证据分层**：保留 agent 方法论模拟，但把真实数据、公开行为、推断和未验证模型分开展示；身份模拟不能替代可复现模型或真实持仓证据。
4. **采集与失败可观测性**：为每个源记录成功率、耗时、覆盖日期与失败原因；pipeline 回退 legacy 时显式报告，避免无解释的整轮重复抓取。
5. **多市场发行人标识**：当前导出使用公司名称作保守核验，名称不一致会拒绝导出。后续使用核验过的发行人 ID 和上市映射，避免简称、繁简体及 A/H 名称差异造成误拒绝。
6. **独立宏观日历 provider**：按市场/日期共享缓存，覆盖时区、夏令时、延期、取消、抓取失败；不把时间已到视为数据已发布。

这些后续项不作为本次已实现功能或效果承诺。
